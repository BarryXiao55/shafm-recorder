## 3. FFmpeg

- FFmpeg 是独立的第三方项目，本项目**不分发、不捆绑、不修改**其二进制文件。
- 发布包中的 `bin/` 只含下载说明；`ffmpeg.exe` / `ffplay.exe` / `ffprobe.exe` 不在包内，用户可用 `tools/install-ffmpeg.js` 一键下载安装（脚本只从公开的第三方构建源下载，**仓库内不内置任何二进制**），或按 `bin/README.md` 手动安装。
- FFmpeg 依据其自身许可证（依构建不同为 LGPL/GPL）分发，请自行查阅并遵守：https://ffmpeg.org/legal.html
- 本项目在未检测到 ffmpeg 时使用自带的零依赖直录引擎，功能等价（按字节原样写盘），不依赖任何第三方运行时。

## 4. Node.js 与前端

- 运行时依赖 Node.js（>=18），本项目不捆绑 Node.js 二进制。
- 前端为原生 HTML/CSS/JavaScript，**无 npm 依赖、无构建步骤、无 CDN 外链**，可完全离线运行。
- 服务仅监听 `127.0.0.1`，不向公网开放，不上传任何录制内容或用户数据。
