电台库管理（查看 / 新增 / 编辑 / 删除 / 测活）

电台库收录上海可收听的 FM 频率：SMG 本地台 + 中央级在沪落地台（如 FM 87.9）。频道 ID 用于抓 EPG 节目表（蜻蜓频道页路径），新增电台可留空，只是没有自动节目表。HLS（.m3u8）流会录成 .ts，依旧零重编码。

上海新闻广播是 FM 93.4 MHz / AM 990 kHz 双频同步、同一套节目；「990」是中波呼号（990 早新闻、news990.cn），不是调频频率，因此本台前缀沿用历史命名 FM990。 FM 99.0 MHz 是另一个电台——中央广播电视总台「中国之声」（央广一套，全国时政新闻），节目内容与上海新闻广播完全不同，本电台库（仅上海本地 FM）未收录它。
当前流已复核为 MPEG-1 Layer III / 64 kbps / 44.1 kHz；地址会变，可用浏览器 F12 → Network 过滤 m3u8/mp3 重新抓取。

落盘设置

最高保真原则：-c copy / 字节原样写盘，不解码、不重编码、不重采样、不改音量，录到的就是电台发出的原始码流，零二次损失。 源流本身是 64 kbps / 44.1 kHz 有损音频，这是音质天花板；改码率、转格式只会再损一次。 内置引擎自动跳过非音频前导并做 MP3 帧对齐，分段精确切在帧边界；HLS 源按 TS 分片字节原样拼接，同样不重编码。

监听方式

仅参数设置

播放控制已移到右侧「并行任务」：每行末尾的「监听」按钮，点亮就听这一路，点灭就停止。 监听是排他的——同一时刻只有一路声音，点另一行会自动停掉上一行。 源不可监听时（HLS .m3u8、空地址）按钮自动灰掉，录制不受影响。 监听走浏览器独立连接，不进入录音文件；刷新页面后播放状态会复位，属浏览器自动播放策略的正常行为。

无损合并（按钮就在上方工具条，蓝色那个）：点「全选可合并」一键勾选全部 .mp3 分段，或自己勾选 2–100 个 .mp3，再点「合并选中分段」——按文件时间顺序按字节拼接，不解码不重编码、零二次损失，原文件保留，生成 MERGE_YYYYmmdd_HHMMSS.mp3。未选够或选错类型时按钮仍可点，会明确告诉你原因。FM 87.9 录出的 .ts 是 HLS/AAC 流，不参与 MP3 合并；正在写入的文件不能合并；合并产物不会被「清理测试文件」自动删除，需手动删。
